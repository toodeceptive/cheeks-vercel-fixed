## PRICING PROPOSAL BASED ON ACTUAL MENU & PROFIT MARGINS

### Model 1: Per-Person Event Fee (Based on Actual Revenue)

**Calculation Method:**
- Take 5-8% of event revenue (owner keeps 92-95%)
- OR flat fee per person based on package

**Package A (Apps + Drinks):**
- Revenue per person: $19
- Fee: $1.00-1.50 per person (5-8% of revenue)
- **20-person event:** $20-30 fee

**Package B (Buffet):**
- Revenue per person: $27.50
- Fee: $1.50-2.20 per person (5-8% of revenue)
- **20-person event:** $30-44 fee

**Package C (Premium):**
- Revenue per person: $42.50
- Fee: $2.13-3.40 per person (5-8% of revenue)
- **20-person event:** $42.60-68 fee

**Recommended:** $2.00 per person per event (flat, regardless of package)
- Simple to calculate
- Fair across all packages
- **20-person event:** $40 fee
- **30-person event:** $60 fee
- **50-person event:** $100 fee

### Model 2: Percentage of Event Revenue

**Calculation:**
- 5-8% of total event revenue
- Based on actual revenue (not estimates)

**Example (20-person Package B event):**
- Revenue: $550
- Fee (5%): $27.50
- Fee (6%): $33
- Fee (8%): $44

**Recommended:** 6% of event revenue
- Aligned with owner's profit margin
- Scales with event size
- Fair for both small and large events

### Model 3: Hybrid (Setup + Per-Person Fee)

**Setup Fee:** $1,500-2,000 (one-time)
**Per-Person Fee:** $1.50-2.00 per person per booked event
**Monthly Minimum:** $200/month (first 6 months)

**Example (20-person event):**
- Setup: $2,000 (one-time)
- Event fee: $30-40 (20 × $1.50-2.00)
- Monthly minimum: $200 (if no events)

**Annual Projection (12 events, avg 20 people):**
- Setup: $2,000
- Events: $360-480 (12 × $30-40)
- Monthly minimums: $1,200 (6 months × $200)
- **Total Year 1:** $3,560-3,680

## RECOMMENDED PRICING MODEL (Based on Real Data)

### Primary Recommendation: Per-Person Event Fee

**Setup Fee:** $1,800 (one-time)
**Per-Person Fee:** $2.00 per person per booked event
**Monthly Retainer:** $250/month (first 6 months, then optional)

**Rationale:**
- Simple to calculate (guests × $2.00)
- Fair across all package types
- Owner keeps 92-95% of revenue
- Predictable for owners
- Scales with event size

**Examples:**
- 15-person event: $30 fee
- 20-person event: $40 fee
- 30-person event: $60 fee
- 50-person event: $100 fee

**Annual Projection (Conservative):**
- 1 event/month, avg 20 people
- 12 events × $40 = $480/year in event fees
- Setup: $1,800
- Retainer (6 months): $1,500
- **Total Year 1:** $3,780
- **Year 2+:** $480/year (events only, no retainer)

**Owner ROI:**
- 20-person Package B event: $550 revenue, $27.50-33 net profit
- System fee: $40
- **Owner still profitable:** Yes (if event is part of regular operations)
- **Value:** System brings in events they wouldn't have had otherwise

## FINAL RECOMMENDATION

**Model:** Per-Person Event Fee
- **Setup:** $1,800
- **Per-Person:** $2.00 per booked event
- **Retainer:** $250/month (first 6 months, then optional)

**Why This Works:**
1. Based on actual menu pricing
2. Fair to owner (they keep 92-95% of revenue)
3. Simple to calculate and track
4. Scales with event size
5. Predictable costs

**Negotiation Range:**
- High: $2,000 setup + $2.50/person + $300/month
- Target: $1,800 setup + $2.00/person + $250/month
- Floor: $1,500 setup + $1.50/person + $200/month
